🎯 **What:**
The `calculate` function previously evaluated mathematical expressions using a custom logic involving `ast.parse` and recursive node evaluation. This custom implementation was susceptible to Denial-of-Service (DoS) via resource exhaustion, specifically excessive recursion or CPU exhaustion with huge powers (e.g. `9**9**9` or deeply nested parentheses).

⚠️ **Risk:**
If an attacker supplied a deeply nested expression or a huge exponentiation expression, the agent evaluation would lock up consuming CPU or crash due to maximum recursion depth being exceeded. This represents a Denial-of-Service (DoS) vulnerability and an issue when handling untrusted inputs dynamically.

🛡️ **Solution:**
Replaced the custom AST-based `safe_eval` with the `simpleeval` library, which provides a highly secure mechanism for evaluating Python expressions. `simpleeval` limits strings, max powers, and operations inherently, thus resolving the DoS vector. The existing character allow-listing was preserved for defense-in-depth, and tests were added to ensure extreme expressions correctly raise the `NumberTooHigh` limit without hanging the process.
