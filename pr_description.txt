⚡ Cache noise calibration

💡 **What:** Caches the result of `calibrate_noise()` using a module-level variable `_cached_silence_threshold` within `agent_core.py`. If `record_until_silence()` is called without an explicit `silence_threshold`, it computes it once and reuses the cached value on subsequent calls.

🎯 **Why:** `calibrate_noise()` defaults to a 1.5-second ambient sampling duration. Because this function is called inside the `voice_loop()` on *every* recording iteration, this added a continuous 1.5 seconds of overhead (latency) before the mic even began listening. By caching the threshold, the latency for all subsequent iterations drops effectively to zero.

📊 **Measured Improvement:**
Baseline (before optimization): 3 iterations took ~7.677s (avg 2.5s per recording + mock logic delay).
After optimization: 3 iterations took ~4.675s (iteration 1 took 2.559s, iterations 2 & 3 took 1.058s).
The time savings is exactly 1.5s per loop iteration (a 100% savings on the calibration cost).
