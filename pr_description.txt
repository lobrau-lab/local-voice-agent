🎯 **What:**
Added extensive testing for `agent_core.py`, which is responsible for audio I/O, speech-to-text, text-to-speech, and agent initialization. This addresses a significant gap in the test suite where the core logic was entirely untested.

📊 **Coverage:**
* `calibrate_noise`: Tested calculation of silence thresholds and handling of minimum noise floors.
* `record_until_silence`: Validated audio recording limits (min/max durations) and tested accurate stop triggers based on simulated silence.
* `transcribe_audio`: Simulated `mlx_whisper` and verified the internal audio resampling functionality.
* `_synthesise` / `speak`: Mocked the `mlx_audio` model generator and validated logic execution, along with checks that prevent empty text from triggering audio play.
* `build_agent`: Tested agent instantiation configuration against mocked `agent_weave` interfaces.

✨ **Result:**
By extensively mocking hardware requirements (like the microphone and speaker) and the large local AI models, `agent_core.py` is now covered by fast, deterministic tests without relying on a complex external environment. Test coverage and reliability are vastly improved.
