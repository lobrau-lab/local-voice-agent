## Installation and Management

You can use the new `cli.py` tool to manage your installation, setup, and running processes for both the agent interface and the server.

```bash
# Setup dependencies and configuration
python3 cli.py setup

# Start both the server and the agent interface
python3 cli.py start

# Check the status of the server and agent
python3 cli.py status

# Stop both the server and the agent interface
python3 cli.py stop
```

For more options, run:
```bash
python3 cli.py --help
```
